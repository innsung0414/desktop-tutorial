# 점프대시 프로토타입 게임 스펙

## 개요

눈 덮인 산에서 스노보드를 타고 자동으로 전진하며 장애물을 피하는 2D 싱글 플레이 게임이다. 플레이어는 점프, 아이템으로 얻는 더블 점프, 대시를 조합해 생존 시간을 늘리고 최고 기록을 갱신한다. 이 문서는 게임의 핵심 플레이 규칙과 화면, 기능 완료 기준을 정의한다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 싱글 플레이 자동 러너 |
| 플랫폼 | PC |
| 엔진 | Unity |
| 배경 및 테마 | 겨울 산악 지형과 스노보드 |
| 조작 방식 | 키보드 |
| 핵심 목표 | 장애물을 피하며 생존하고 최고 기록을 갱신 |

## 디자인 목표

- 누구나 바로 시작할 수 있는 간단한 조작을 제공한다.
- 점프와 대시를 사용할 시점을 판단하는 숙련도가 생존 기록에 영향을 주도록 한다.
- 짧은 플레이와 빠른 재도전을 지원해 최고 기록 갱신을 반복해서 시도할 수 있게 한다.
- 시간이 흐를수록 이동 속도와 장애물 생성 빈도를 높여 도전 강도를 키운다.
- 개인 최고 기록을 저장하고, 친구와 기록을 비교할 수 있는 경험을 제공한다.

## 게임 진행 흐름

1. 타이틀 대기 중 실제 MainScene의 활강 장면이 화면 전체를 채우고 그 위에 게임명, START 버튼, 조작 안내, 로컬 상위 5개 기록을 표시한다. Enter/Space 또는 START 버튼을 누르면 메뉴가 0.75초 동안 사라지고 HUD가 나타난다. 같은 캐릭터·카메라·지형을 유지한 채 점수와 난이도, 장애물 생성을 시작한다.
2. 플레이어가 자동으로 전진하고, 플레이 시간이 점수로 누적된다.
3. 플레이어는 점프, 더블 점프, 대시로 장애물을 피하고 더블 점프 아이템을 획득한다.
4. 플레이 중 Escape를 누르면 점수·이동·장애물 진행을 멈추고 일시정지 메뉴를 연다. 메뉴에서 재개, 설정, 타이틀 복귀, 게임 종료를 선택할 수 있다.
5. 설정에서는 전체 음량과 전체 화면 여부를 조절한다. 변경 값은 다음 실행에도 유지된다.
6. 시간이 흐를수록 플레이어 이동 속도와 장애물 생성 빈도가 증가한다.
7. 장애물과 충돌하면 게임이 종료되고 현재 기록과 로컬 상위 5개 기록을 확인한다. 이번 기록이 상위 5위 안에 들면 닉네임을 입력해 저장한다.
8. 닉네임을 저장하거나 기록 등록을 건너뛰고 재도전해 이전 기록을 넘는 것을 목표로 한다.

## 조작

| 입력 | 동작 | 규칙 |
| --- | --- | --- |
| Space | 점프 | 지면에 있을 때 점프한다. 공중에서는 더블 점프 횟수가 남아 있을 때 추가 점프를 할 수 있다. |
| Tab | 대시 | 전방으로 짧게 가속한다. 사용 후 쿨타임이 끝나야 다시 사용할 수 있다. |
| R | 재시작 | 게임 오버 상태에서 현재 플레이를 다시 시작한다. |
| 마우스 클릭 | 게임 시작 | 타이틀 화면의 START 버튼을 선택한다. |
| Enter / Space | 시작 또는 기록 저장 | 타이틀 화면에서는 게임을 시작한다. 게임 오버에서 기록 등록 자격이 있으면 닉네임을 저장한다. 플레이 중 Space는 점프 입력이다. |
| Escape | 일시정지 / 기록 등록 건너뛰기 | 플레이 중 메뉴를 열고 닫는다. 설정 화면에서는 일시정지 메뉴로 돌아간다. 게임 오버에서는 닉네임 입력을 건너뛰거나 재도전한다. |

좌우 이동 입력은 사용하지 않는다. 플레이어는 자동으로 전진한다.

일시정지 메뉴는 재개, 설정, 타이틀 복귀, 게임 종료 버튼을 제공한다. 설정은 전체 음량과 창/전체 화면 모드를 제공하며 변경 값을 로컬에 저장한다.

## 게임 시스템

### 이동과 난이도

플레이어는 초당 5 Unity 단위로 자동 전진하고, 생존 초당 0.055씩 속도가 계속 증가한다. 이동 속도에는 상한을 두지 않는다. 따라서 60초에는 초속 8.3, 120초에는 11.6, 180초에는 14.9에 도달하며 3분 생존은 숙련된 장기 기록으로 삼는다. 대시는 현재 이동 속도보다 초당 20 Unity 단위 빠른 속도를 유지한다. 장애물 생성은 2.4–3.2초 간격에서 시작하고 초당 0.025초씩 줄어들되, 각각 1.35초와 1.9초보다 짧아지지 않는다. 장애물 패턴이 서로 겹치지 않도록 마지막 장애물과 다음 패턴 사이에도 최소 11 Unity 단위 공간을 둔다.

### 점프와 더블 점프

Space 키로 지면에서 점프한다. 플레이어는 시작할 때 더블 점프 횟수를 보유하지 않는다. 더블 점프 아이템 하나를 획득하면 공중에서 사용할 수 있는 추가 점프 기회 하나를 얻는다. 공중에서 Space 키를 누르면 기회 하나를 소비한다.

화면에는 남은 더블 점프 횟수를 표시한다. 점프와 더블 점프에는 점프 효과음을 재생하고, 더블 점프 사용 시 파티클 효과를 표시한다.

더블 점프 아이템은 설면 위에서 천천히 회전하며 청록색 얼음빛 외곽광으로 강조한다. 획득하면 기존 아이템 파티클 프리팹 대신 청록·빙백색·푸른 보랏빛 팔레트의 후광과 이중 확장 링, 짙은 코발트 외곽선, 중심 섬광·눈꽃 반짝임, 얼음 파편 12개와 눈 결정 반짝임 24개를 약 0.9초 동안 재생한다. 중심 아이콘은 후광의 빈 공간 위에 표시해 빛에 묻히지 않게 한다. 아이템 획득 효과음은 그대로 유지한다.

### 대시

Tab 키로 전방 대시를 사용한다. 대시 입력 시 쿨타임이 시작되며, 쿨타임 UI가 재사용 가능 시점을 보여준다. 대시에는 효과음을 재생한다.

### 장애물

장애물은 Small, Tall, Wide 세 종류를 사용한다. 각 투명 겨울 스프라이트에는 파란 배경과 대비되는 따뜻한 주황색 외곽선을 더한다. 생성 시 설면 충돌선에서 각 충돌체의 바닥을 맞춘 뒤, 아트의 폭과 높이를 충돌 영역에 맞추고 Small·Wide의 투명한 아래쪽 여백만큼 시각 아트를 더 내려 눈에 닿게 한다. Tall의 정렬은 현재 만족스러운 상태로 유지한다. 총 16개 패턴은 단일 장애물과 두세 개의 넉넉히 간격을 둔 혼합 배치다. 초반 18초 동안 읽기 쉬운 6개 패턴만 사용하고, 18초 이후 11개, 42초 이후 전체 16개를 추가한다. 같은 패턴 안의 연속 장애물은 최소 약 11 Unity 단위 떨어뜨리고, 묶음과 묶음 사이에도 최소 11 Unity 단위 공간을 둬 차례로 피할 시간을 확보한다. 장애물과 충돌하면 즉시 게임 오버 상태가 된다.

플레이어의 둥근 피격 영역은 캐릭터 중심부에 맞춘 CapsuleCollider2D 0.40×0.45 Unity 단위다. 팔과 스노보드 끝부분을 피격 영역에서 제외해 그림 가장자리가 스치기만 해도 충돌하는 느낌을 줄인다.

### 아이템

더블 점프 아이템은 플레이어 앞쪽에 생성하며 설면에서 약 1.1–1.55 Unity 단위 위에 배치해 기본 점프로 획득할 수 있게 한다. 얼음 아이콘을 기존 런타임 크기보다 약 17% 키우고, 짙은 코발트 실루엣·밝은 금빛과 청록색 링·세로 신호 빔·맥동 후광으로 숲과 설면 양쪽에서 즉시 구별되게 한다. 아이템은 원래 얼음 결정 색을 유지하며 느리게 부유·회전한다. 아이템을 획득하면 더블 점프 횟수를 하나 추가하고 효과음을 재생한다. 획득 연출은 청록·빙백색·푸른 보랏빛 팔레트의 후광과 이중 확장 링, 짙은 코발트 외곽선, 중심 섬광·눈꽃 반짝임, 얼음 파편 12개와 눈 결정 반짝임 24개를 약 0.9초 동안 재생한다. 이 획득 연출은 상시 아이템 표시의 금빛 신호 링과 분리된 팔레트다. 아이템의 출현 간격은 8–15초로 유지한다.

### 점수와 기록

점수는 생존 시간이며 초 단위로 표시한다. 로컬 아케이드 기록은 생존 시간이 긴 순서로 최대 5개까지 저장한다. 게임 오버 시 현재 기록이 상위 5위 안에 들면 닉네임(최대 12자)을 입력해 제출할 수 있다. 제출된 기록만 순위표에 반영하며, 상위 5위 밖의 기록은 저장하지 않는다. 순위표는 타이틀과 게임 오버 화면에서 확인하고, 로컬 저장소에 보존한다. 이전 버전의 이름 없는 개인 최고 기록이 있으면 `PLAYER` 이름으로 순위표에 한 번 이전한다.

친구와 기록을 비교하는 기능은 디자인 목표에 포함한다. 온라인 리더보드, 플랫폼 친구 연동, 기록 공유 등 구체적인 제공 방식은 별도 결정이 필요하다.

### 게임 오버와 재도전

장애물 충돌 시 점수 증가와 플레이를 멈추고 게임 오버 UI를 표시한다. 충돌 효과음과 카메라 흔들림을 재생한다. 현재 기록과 최고 기록을 확인할 수 있으며 R 키로 다시 시작한다.

## 화면 구성

| 화면 | 필수 요소 |
| --- | --- |
| 타이틀 화면 | 화면 전체에서 실제 플레이어가 활강하는 MainScene, 그 위에 게임명·START RIDING·Space/Tab 조작 안내·로컬 상위 5개 기록을 배치한 메뉴 |
| 게임 플레이 화면 | 플레이어와 배경, 반응형 Canvas HUD, 현재 생존 시간과 최고 기록, 이동 속도 배수, 더블 점프 아이콘·잔여 횟수, 대시 충전 막대와 준비 상태 |
| 게임 오버 화면 | 화면을 어둡게 덮는 오버레이, 생존 시간과 로컬 상위 5개 순위표, 상위 5위 달성 시 닉네임 입력·저장 UI, 클릭 가능한 재도전 및 건너뛰기 버튼 |

### 화면 크기와 UI 스타일

- 타이틀과 플레이 HUD는 1920×1080 기준 해상도를 사용하고 `Scale With Screen Size`로 비율에 맞춰 축소·확대한다.
- 타이틀은 실제 플레이 장면 위에 UI를 얹는 전체 화면 어트랙트 모드다. 과거의 별도 타이틀 배경과 작은 캐비닛 미리보기는 제거한다. 대기 중에는 실제 라이더가 초기 속도로 계속 활강하고, 점수·속도 증가·장애물·아이템 생성과 조작은 대기한다.
- 시작 시 같은 MainScene과 플레이어·카메라·지형을 그대로 유지한다. 메뉴가 0.75초 동안 페이드아웃하고 플레이 HUD가 페이드인한 뒤 조작과 점수 집계를 시작한다. 타이틀 대기 시간은 장애물 난이도나 점수에 포함하지 않으며 첫 장애물 패턴은 플레이가 시작된 뒤 2초 후 생성한다.
- 플레이 중 기록은 왼쪽 위, 속도 배수는 위쪽 중앙, 더블 점프 잔여 횟수는 오른쪽 위, 대시 충전 상태는 왼쪽 아래에 둔다. 짙은 남색 카드, 청록 강조색, 크기 대비가 큰 숫자와 상태 아이콘으로 설경 위에서도 읽히는 아케이드 HUD를 만든다.
- 게임 오버에서는 현재 기록과 최고 기록을 같은 카드에서 비교하고, R 키와 클릭 버튼을 모두 제공한다.

### 장르 레퍼런스

- [Alto’s Adventure 공식 프레스 키트](https://altosadventure.com/press/spiritofthemountain/)가 설명하는 절제되고 손그림 같은 산악 표현을 참고한다. 이 프로토타입에서는 기존 파노라마를 살리고 메뉴 요소 수를 줄여 타이틀 시각 우선순위를 만든다.
- [Ski Safari 공식 페이지](https://skisafari.sleepyzstudios.com/)와 [Ski Safari 2 App Store 소개](https://apps.apple.com/us/app/ski-safari-2/id952555810)가 강조하는 끝없는 하강과 파워업·기록 경쟁 흐름을 참고한다. 이에 따라 생존 기록, 더블 점프 아이템, 대시 충전 상태를 플레이 중 즉시 확인할 수 있게 배치한다.

## 오디오와 시각 효과

- 점프 효과음
- 대시 효과음
- 충돌 효과음
- 아이템 획득 효과음
- 더블 점프 파티클
- 아이템 획득 파티클
- 장애물 충돌 시 카메라 흔들림
- 겨울 산악 배경과 스노보드 플레이어 표현

### 비주얼 방향

- 플레이어는 흰 헬멧과 어두운 테두리, 청록 바이저, 파란 겨울 재킷, 어두운 바지·부츠, 청록 스노보드를 갖춘 단일 투명 스프라이트로 표현한다. 낮게 웅크려 오른쪽을 향해 활강하는 자세를 사용한다.
- 배경은 푸른 겨울 하늘, 눈 덮인 산맥, 짙은 청색 전나무가 이어지는 넓은 파노라마로 구성한다. 좌우를 반복해도 눈에 띄는 경계가 생기지 않도록 한다.
- 캐릭터와 배경은 밝고 선명한 청색 계열의 손그림풍 2D 아트로 통일하며, 플레이어 실루엣이 배경에서 쉽게 구분되어야 한다.
- 더블 점프 아이템은 투명 배경의 푸른 얼음 결정 아이콘으로 표현한다. 아이콘 안에 위쪽 화살표 두 개를 배치해 추가 점프 기능을 알아보기 쉽게 한다.
- 지면은 밝은 설면과 청록·짙은 파랑의 단단한 눈층이 보이는 가로형 전경 스프라이트로 표현한다. 배경 파노라마와 같은 손그림풍을 사용하고, 반복 구간의 좌우 경계가 자연스럽게 이어져야 한다. 설면 최상단은 기존 충돌 영역의 발판 높이와 맞춘다. 시각용 빙층은 화면 하단까지 자연스럽게 이어져 단색 공백이 남지 않게 하되, 그래픽 확장으로 충돌 크기와 GroundLooper의 폭을 바꾸지 않는다.
- 장애물은 서로 구별되는 크기와 실루엣을 쓴다. Small은 낮은 눈덮인 얼음 바위, Tall은 수직 얼음 전나무, Wide는 넓고 낮은 빙하 단층으로 표현한다. 각 스프라이트의 바닥을 설면 충돌선에 맞추고 충돌 박스를 실제 보이는 폭·높이에 맞춘다.

## 완료 기준

- 타이틀 화면의 START 버튼으로 플레이 화면에 진입할 수 있다.
- 플레이어가 자동으로 전진하고 생존 시간이 점수로 증가한다.
- 플레이 시간에 따라 이동 속도와 장애물 생성 빈도가 증가한다.
- 지면에서 점프하고, 더블 점프 아이템을 획득한 뒤 공중에서 추가 점프를 한 번 사용할 수 있다.
- 더블 점프를 사용하면 보유 횟수가 감소하고, UI가 남은 횟수를 반영한다.
- Tab 대시가 쿨타임을 적용하며, UI에서 쿨타임 상태를 확인할 수 있다.
- Small, Tall, Wide 장애물이 여러 배치 패턴으로 등장한다.
- 타이틀 대기 중 실제 활강 장면이 전체 화면에 계속 재생되며, Enter/Space/START 선택은 메뉴와 HUD의 페이드 전환을 시작한다.
- 시작 전후에 씬을 다시 불러오거나 플레이어·카메라를 교체하지 않고 위치와 이동을 유지한다. 전환이 끝난 시점부터 점수·난이도·장애물·아이템 및 플레이 입력이 활성화된다.
- 타이틀 어트랙트 모드에서 라이더는 직진하고 배경·설면은 끊김 없이 흐르며, 장애물 회피와 실제 기록 변경은 발생하지 않는다.
- 반복 지면의 충돌 면은 연결되어 캐릭터가 구간 이음새에 걸리지 않아야 한다. 각 지면의 폭·높이·설면 위치와 시각 아트는 유지한다.
- 플레이어는 중심부를 덮는 0.40×0.45 단위 Capsule 피격 영역을 사용하며, 팔과 보드 끝은 충돌 판정에서 제외한다.
- 장애물은 따뜻한 색 외곽선으로 배경에서 분명히 구분하고, 충돌체와 그림의 바닥을 설면에 맞춘다. 생성 패턴 사이에 피할 시간을 두고 장애물 생성 간격 하한을 지킨다. 이동 속도는 생존 시간에 따라 상한 없이 증가한다.
- 더블 점프 아이템은 짙은 남색 키라인, 금빛·청록 신호 링, 세로 빔과 맥동 후광으로 눈에 잘 띄며 기본 점프 높이에서 획득할 수 있다. 획득 시 기존 파티클 프리팹과 주황색 획득 연출을 사용하지 않고, 중심 아이콘을 살린 코발트 테두리 이중 링·빙백색 섬광·얼음 파편·눈꽃 반짝임의 절차형 연출을 표시한다. 효과음은 유지한다.
- 인게임 HUD에서 생존 시간, 최고 기록, 속도 배수, 더블 점프 잔여 횟수, 대시 충전 상태를 확인한다.
- 장애물 3종이 각기 다른 아트 스프라이트와 크기에 맞춘 충돌 영역으로 나타나며, 진행 구간별로 다양한 배치 패턴을 사용한다.
- 충돌 시 플레이와 점수 증가가 멈추고 게임 오버 UI, 충돌 효과음, 카메라 흔들림이 표시된다.
- 플레이 중 Escape로 정지 메뉴를 열면 시간·물리·장애물 진행이 멈추고, 재개하면 이어서 진행된다. 설정 화면에서 전체 음량과 화면 모드를 바꿀 수 있고, 타이틀 복귀 및 게임 종료가 동작한다.
- 음량과 화면 모드 설정은 게임을 다시 실행한 뒤에도 유지된다.
- 현재 기록과 최고 기록을 확인할 수 있고, R 키로 재도전할 수 있다.
- 최고 기록이 다음 플레이와 게임 재실행 후에도 유지된다.
- 로컬 순위표는 점수 내림차순 상위 5개만 보존하고 재실행 후에도 유지된다.
- 게임 오버에서 상위 5위에 들어간 기록은 닉네임 입력 후 저장되며, 상위 5위 밖의 기록은 저장되지 않는다.
- 점프, 대시, 충돌, 아이템 획득에 해당하는 효과음과 필요한 파티클 효과가 재생된다.

## 추가 결정이 필요한 항목

- 친구 기록 비교를 위한 리더보드 또는 기록 공유 방식
- 아이템 출현 확률과 난이도에 따른 조정 여부
- 최종 화면 해상도, UI 언어, 접근성 설정
